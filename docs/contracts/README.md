# 公共层 D 契约文档

本目录是 ADR-0004 §5.3 规定的契约登记处。**代码与文档在同一个 MR 内更新**，两者不一致以本文档为准并立即修代码。

## 1. 子域与 owner

| 子域 | 范围 | Owner | 契约文档 | 状态 |
|------|------|-------|----------|------|
| D1 身份与权限 | 用户/角色/权限、RBAC 守卫、审批权限码 | M2 | `d1-rbac.md` | 未建 |
| D2 空间与座位主数据 | 自习室/教室/座位登记、可用性维护 | M1 | `d2-master-data.md` | 未建 |

D1~D3 由 owner 各自补，本目录只提供统一格式，不代写。

## 2. 治理规则（摘自 ADR-0004 §5）

1. D 对外只暴露 **Service 方法签名与 DTO**，不导出 TypeORM Entity 给其他模块使用。
2. 接口变更走 `contract-change` 标签的 MR，由其余两人 review 后才能合并。
3. 契约文档与代码在同一个 MR 里更新。
4. 禁止跨模块直连表。确需只读共享的，必须在 ADR-0004 §5.4 登记例外（表、字段、原因、审批人）。

## 3. 每份契约必须写清的六件事

| 项 | 说明 |
|----|------|
| 方法签名 | TypeScript 签名，含返回类型 |
| 失败语义 | 抛错、返回空、静默忽略，三者必须明确选一个 |
| 幂等性 | 重复调用是否产生重复副作用 |
| 边界条件 | 空输入、越权、超量、跨模块误用 |
| 消费方登记 | 谁在用、用哪个方法、什么场景 |
| 未实现项 | 明确标注，不允许用「后续完善」含糊带过 |
